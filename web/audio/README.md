# 欢迎语音频

面板在动画收尾时会播一句欢迎语（v1.9.2 起只出声，屏幕上不再显示文字），默认播这两个文件（都在本地，不依赖系统语音）：

| 文件 | 什么时候播 |
| --- | --- |
| `welcome-master.mp3` | 非中文系统，念 "Welcome back, master." |
| `welcome-master-zh.mp3` | 中文系统，念「欢迎回来，主人。」 |

- 想换自己的录音：直接覆盖同名文件即可，代码里带了 `?v=2` 缓存戳，改完强刷一次就能听到新的
- 时长建议 2 秒以内，太长会盖住后面的状态面板
- 两个文件都没有才会退回浏览器合成声；合成声被拦或内核不支持时补一下 `blip-soft.mp3`，不会全场静音
- 面板上「欢迎语」那个勾去掉就整段不再出声
