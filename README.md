# 550C 操作台（550C Console）

> 550C 无人机基站开机动画 + 实时状态操作台，作为 KiraAI 面板插件页接入。

仓库：https://github.com/kingzhen1/550c-console

把 550C 单页动画接进 KiraAI 面板：动画结束后展示适配器与主机实时状态，
收起待机时保留 550C 动态台标，并可随时拉出当日报错列表框与用量/金额视图。
1.8.0 起还顺手把「插件更新」这件事办了：定时对照市场给已装插件换新版，换前备份、失败回滚、连续失败拉黑——绝不装新插件，也绝不动自己。

## 功能

- **开机动画**：`simple`（只放标识点亮）/ `full`（完整流程：自检→鉴权→链路→隧道→隔离→重写→校验→就绪→完成）/ `off`（只留黑屏待机）
- **四套配色**：`amber` 原稿琥珀 / `green` / `cyan` / `white`，只换基础色，亮度层次保持原样
- **自动播放与重播**：打开面板即播、可循环、可手动重播；音效可单独关闭
- **实时状态台**：动画结束展示 NapCat / 适配器链路、模型、插件与主机负载；收起后叠实时时钟、链路与在线时长、CPU/内存/磁盘、版本号
- **当日报错列表框**：按级别（ERROR / WARNING）筛选、展开堆栈、一键复制，并附逐条匹配的处理方案
- **用量三视图**：`概览 / 模型 / 金额`，按模型统计调用与 token，并按内置价目表折算 24h 已用金额（人民币，缓存命中单独计价，可用 `prices.json` 外挂补价）
- **趋势折线**（v1.7.0）：每次轮询把 CPU / 内存 / 磁盘 / token 采样落盘，状态面板底部画三条 canvas 折线，磁盘这类「缓慢爬升」的指标才看得出还有多久满
- **阈值告警**（v1.7.0）：内存 / 磁盘 / CPU 越线，或适配器 `dead` / ws 断开 / 已连接未登录时，面板顶部亮横幅；同一告警 10 分钟内只推一次，配了 `alert_webhook` 还会 POST JSON 出去
- **日报 / 周报导出**（v1.7.0）：状态面板右上两个按钮，把当前主机、趋势极值、24h 用量（含按模型明细与未配价提示）、当前告警、报错归并表拼成一份 Markdown 直接下载
- **诊断包**（v1.7.0）：把当前状态、适配器链路、告警、报错归并、趋势采样打成一个 JSON 整份下载，排查时直接发这一份
- **投屏页接地**（v1.7.0）：`show.html` 的 UPLINK / NODES / SESSION 原来是硬编码演示值，现在接收面板 postMessage 的真实状态
- **插件自动更新**（v1.8.0）：后台一条协程，按设定间隔（默认 6 小时）对照市场清单，把**已经装在本机**、市场里有新版的插件换到新版。换之前整份备份旧目录，换完加载不上或插件身份对不上就原地回滚；同一插件连续失败两次自动拉黑，等人点一下才放出来。只更新、不新装，`550C` 自己与 `kira_ops` 硬性排除。状态面板底部「UPDATE · 插件自动更新」可看上次/下次、待更新清单、黑名单与最近记录，也能手动点「立即检查」

- **框架本体自动更新**（v1.9.0）：`fwupdater.py` 去看 `KiraAI-Dev/KiraAI` 的 release，只认比当前 VERSION 新的（默认也认 beta，可在面板上一键改成只认正式版）。换的是源码包 + WebUI dist 包两样，换前整份备份，装依赖、编译自检、导入冒烟全过才提交，任何一步不对就原地回滚——**绝不带着半成品重启**。只有全都过了才 `os._exit(42)` 交给 supervisor 拉起新进程。默认**关**，因为换框架等于重启整个天网。状态面板「FRAMEWORK · 框架更新」可看当前/最新版本、上次下次检查、release 列表、换版记录，也能手动点「检查并更新」
- **趋势定点查看**（v1.9.0）：趋势折线上挪鼠标或用手指按住，竖虚线跟着走，浮层显示那一刻的时间、CPU、内存、磁盘与 tokens；点一下定点、再点一次松开。单指标模式下浮层只跟那条线，标尺也跟着自适应

- **框架更新不再被匿名限额卡住**：查 release 复用 `github-tool` 里配好的 token（`fwupdater.py` 直接读插件配置），没 token 才退回匿名请求；撞到 GitHub 60 次/时的匿名限额时，错误文案由「检查失败」改成「这轮没拉到，下轮再说」，红色报错不再刷屏。
- **版本号**：`manifest.json` 抬到 `1.9.2`。

### v1.9.1

- **欢迎语放大**：`19px` 一句小字改成 `clamp(30px, 7.6vw, 76px)`，字重 600、字距收到 `.14em`、光晕加厚一层，手机上跟着屏宽走，桌面上封顶 76px。（v1.9.2 起这行字已按需求删除，只保留声音）
- **欢迎语有声音了**：内置 `web/audio/welcome-master.mp3`（英文 "Welcome back, master."）与 `welcome-master-zh.mp3`（中文「欢迎回来，主人。」），中文系统自动用中文那份。音量从 `0.9` 拉到 `1`，峰值归一化到 −1.5 dB，头尾静音裁掉，整句 1.5 秒。
- **不再全场静音**：没有音频文件才退回浏览器合成声；合成声被拦、内核不支持、或 `speak()` 了却没声（900 ms 内既不在 `speaking` 也不在 `pending`），补一记 `blip-soft.mp3` 兜底提示音。
- **防缓存**：音频请求带 `?v=2`，换文件后强刷即可生效。
- **插件点灯修正**：本地版本比市场新（例如自己改过版本号，出现「v1.9.0 → 1.8.0」）时不再显示箭头——升级逻辑本来就会挡掉降级，显示上也不该像要回退。
- **折叠交互加重**：`UPDATE` / `FRAMEWORK` 两段的折叠键从一枚细字符换成 18px 描边方块 + 实心三角，整行标题也可点。

## 安装

1. KiraAI 面板 → 插件商店 → 搜索 `550C`，或直接从 GitHub Release 安装
2. 需要 KiraAI `core_version >= 2.23.0`

手动安装：下载 Release 附件解压到 `data/plugins/kira-ai-plugin-550c-boot/`，重启 KiraAI。

## 配置

面板 → 插件 → 550C 开机动画：

| 项 | 说明 |
| --- | --- |
| `mode` | 播放模式：simple / full / off |
| `scheme` | 配色：amber / green / cyan / white |
| `auto_play` | 打开面板即自动播放 |
| `loop` | 放完自动重播 |
| `duration_hint` | 完整模式时长提示（秒） |
| `alert_enabled` | 阈值告警总开关（v1.7.0） |
| `alert_disk` / `alert_mem` / `alert_cpu` | 三条告警阈值，默认 90 / 90 / 95（v1.7.0） |
| `trend_hours` | 趋势折线画多长时间，默认 24 小时（v1.7.0） |
| `auto_update` | 插件自动更新总开关，默认开（v1.8.0） |
| `update_interval_hours` | 多久检查一次，1~168 小时，默认 6（v1.8.0） |
| `update_max_per_run` | 每轮最多更新几个，1~10，默认 3（v1.8.0） |
| `update_exclude` | 永不更新的 plugin_id，逗号分隔（v1.8.0） |
| `fw_auto_update` | 框架自动更新总开关，**默认关**（v1.9.0） |
| `fw_update_interval_hours` | 框架多久查一次，1~168 小时，默认 24（v1.9.0） |
| `fw_allow_prerelease` | 框架是否允许预发布版，默认允许（v1.9.0） |
| `sfx` | 音效开关 |
| `github_token` 等 | 见面板内 schema 说明 |

金额视图的价目表可用插件目录下的 `prices.json` 覆盖，单位：元 / 每百万 token。

**Webhook（v1.7.0）**：`alert_webhook` 没做进面板 schema（避免未知字段类型让配置校验整体失败），需要时直接写进插件配置文件，值填 `http(s)://…`。触发时 POST：

```json
{"source": "550C 操作台", "ts": 1793500000,
 "alerts": [{"id": "host-disk", "lv": "bad", "title": "磁盘 97.2%", "detail": "已超过阈值 90%"}]}
```

同一 `id` 在 10 分钟内只推一次；请求超时 5 秒，失败只记一条 warn，不影响面板接口。

## 目录结构

```
main.py              插件后端：状态采集、报错聚合、用量与金额折算、采样与告警、自动更新接口
updater.py           插件自动更新器：市场比对、备份、替换、重载验证、回滚、黑名单
schema.json          插件配置项定义
web/index.html       控制台页面（动画 + 状态台 + 趋势折线 + 报错池 + 用量 + 导出）
web/show.html        投屏/展示页
web/audio/*          音效
assets/550C-source.html  原稿动画（只读参考）
scripts/gen.py       原稿 → 面板页的定点改写脚本
selftest.py          离线自测（假 core.plugin 桩，跑告警/报告/采样/自动更新，56 项断言）
samples.jsonl        运行时生成：趋势采样点，可随时删，删了曲线从头累积
```

改完后端逻辑先跑 `python3 selftest.py`，不用装到 KiraAI 上也能发现字段名对不上这类问题。
